# TASTEFRAME — Personal Motion Director

**คุยครั้งเดียว** — TASTEFRAME สัมภาษณ์คุณครั้งเดียวให้เข้าใจรสนิยมของคุณจริงๆ แล้วสร้างคลิป motion graphics ให้เองจนจบ **end-to-end แบบอัตโนมัติ (Autonomous)** ไม่ต้องมานั่งตอบคำถามจุกจิกกลางทาง และไม่ต้องได้งานหน้าตาเหมือนของคนอื่น เพราะทุกการตัดสินใจยึดโปรไฟล์รสนิยมของคุณเป็นกฎหมาย

TASTEFRAME คือสกิลสำหรับเอเจนต์ AI (เช่น Claude Code, Cursor) — คุณคุยกับเอเจนต์เป็นภาษาคนธรรมดา ไม่ต้องรู้ศัพท์เทคนิค เอเจนต์แปลทุกอย่างเป็นงานผลิตให้เอง

## ฉบับ FREE นี้มีอะไรบ้าง

- **ระบบสัมภาษณ์ครั้งเดียวจบ (Grill)** — คำถามแบบกดเลือกพร้อมตัวเลือกแนะนำ ถามทีเดียวครบ: สี ฟอนต์ จังหวะการตัด เสียง งานที่ชอบและงานที่เกลียด
- **โปรไฟล์ TASTE.md** — ไฟล์รสนิยมประจำตัวของคุณ เก็บไว้ใช้ซ้ำทุกคลิป ไม่ต้องเริ่มอธิบายใหม่
- **ท่อผลิตครบวงจร** — บรีฟ → ผู้กำกับวางแผนช็อต → สร้าง → ตรวจคุณภาพ (QA) → เรนเดอร์ไฟล์สุดท้าย
- **โหมด Remotion** — สร้างโมชันกราฟิกด้วยโค้ด ลื่น สะอาด สไตล์แอปสมัยใหม่
- **เทมเพลตฉาก 2 แบบ** — คลิปสินค้า และคลิป affiliate ขายของ
- **สถาปัตยกรรมแบบ on-demand** — สกิลถูกออกแบบเชิงวิศวกรรมให้โหลดเฉพาะไฟล์ที่งานนั้นต้องใช้ ไม่ยัดทุกอย่างใส่ทุกครั้ง: เบา เร็ว และประหยัดต้นทุนการรัน (*engineered, not dumped*)

## ติดตั้ง

**วิธีที่ 1 — คำสั่งเดียว (แนะนำ)**

```bash
npx skills add Grunte12/tasteframe-free
```

> ⚠️ `Grunte12` คือตัวยึดตำแหน่ง (placeholder) — ตอนเผยแพร่จริงให้แทนด้วยชื่อเจ้าของ GitHub repo ของโปรเจกต์นี้

**วิธีที่ 2 — โหลด ZIP จาก GitHub**

เปิดหน้า repo นี้ → ปุ่ม **Code** → **Download ZIP** → แตกไฟล์ แล้ววางโฟลเดอร์ไว้ในโฟลเดอร์ skills ของเอเจนต์ที่คุณใช้

## วิธีทำงาน (4 ขั้น)

1. **สัมภาษณ์ครั้งเดียว** — ตอบคำถามกดเลือกสั้นๆ เรื่องรสนิยมและงานที่อยากได้
2. **ได้ TASTE.md** — โปรไฟล์รสนิยม + บรีฟ + แบบร่างงาน ยืนยันเป็นชุดเดียวก่อนเริ่มสร้าง
3. **สร้างอัตโนมัติ** — เอเจนต์กำกับ ผลิต และตรวจงานเองจนจบ ไม่ถามระหว่างทาง
4. **ไฟล์ final** — คลิปพร้อมใช้ ผ่านการตรวจคุณภาพแล้ว

## ฉบับอื่น

มีฉบับ **PRO** และ **ELITE** ที่เพิ่มคลังสูตรช็อต เทคนิค และสไตล์เต็มชุด โหมดสร้างแบบผสม (Hybrid/HyperFrames) ระบบออกแบบเสียง งาน 3D และโมดูลส่งต่องานตัดต่อ — ดูรายละเอียดในช่องทางจำหน่ายของโปรเจกต์
