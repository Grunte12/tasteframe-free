# TASTEFRAME — Personal Motion Director (Free Edition)

AI Agent skill ที่เปลี่ยนคำสั่งภาษาคนเป็นคลิป Motion Graphics อัตโนมัติ (End-to-End) ผ่านระบบสัมภาษณ์รสนิยมครั้งเดียวจบ

---

## ⚡ ติดตั้งด่วน (Quick Start)

### วิธีที่ 1: ติดตั้งผ่าน npx skills (แนะนำ)
```bash
npx skills add Grunte12/tasteframe-free
```

### วิธีที่ 2: โหลด ZIP
1. กดปุ่ม **Code** > **Download ZIP** บน GitHub
2. แตกไฟล์แล้วนำโฟลเดอร์ไปวางที่:
   - **Claude Code:** `~/.claude/skills/tasteframe/`
   - **Cursor / อื่นๆ:** โฟลเดอร์ `skills/` ของเอเจนต์ที่คุณใช้งาน

---

## 🎬 วิธีใช้งาน

เปิดแชตกับ AI Agent แล้วพิมพ์:
> "ใช้ TASTEFRAME ทำคลิป [ระบุงานที่ต้องการ เช่น คลิปขายสินค้า / คลิป affiliate]"

เอเจนต์จะเริ่มสัมภาษณ์สั้นๆ เพื่อสร้าง **TASTE.md** (โปรไฟล์รสนิยมของคุณ) แล้วสร้างคลิปจนจบโดยอัตโนมัติ

---

## 📦 สิ่งที่มีในฉบับ Free

- **ระบบสัมภาษณ์รสนิยม (Grill):** ถามครบในรอบเดียว ทั้งมู้ดโทน สี ฟอนต์ และจังหวะ
- **โปรไฟล์ TASTE.md:** บันทึกรสนิยมไว้ใช้ซ้ำได้ทุกคลิป ไม่ต้องเริ่มอธิบายใหม่
- **ท่อผลิตอัตโนมัติ:** วางโครงเรื่อง → กำกับช็อต → สร้างงาน → ตรวจคุณภาพ (QA) → เรนเดอร์คลิป
- **เรนเดอร์ด้วย Remotion:** สร้างโมชันกราฟิกด้วยโค้ด คุณภาพคมชัด ลื่นไหล
- **เทมเพลตมาตรฐาน:** ฉากคลิปสินค้า และคลิป affiliate
