# เทมเพลตฉาก: รีวิว Affiliate (TikTok Shop / Shopee)

**ชื่อเทมเพลต:** Affiliate Review 15s — หยุดเลื่อน → ใช้จริง → เทียบให้เห็น → ราคา + โค้ด → ปักตะกร้า
**เหมาะกับ:** ครีเอเตอร์ affiliate ขายสินค้าใน TikTok Shop / Shopee Video / Reels ที่มีตะกร้าสินค้าและโค้ดส่วนลด
**โครงสร้างจังหวะ:** hook "หยุดเลื่อน" (2 วิ) → unbox / หยิบใช้จริง (4 วิ) → before/after หรือเทียบ (4 วิ) → ราคา + โค้ด slam (3 วิ) → ปักตะกร้า CTA (2 วิ)

## ขยายเป็น 30 วิ

- เพิ่มบีต **เทสต์โหด / ทดสอบให้เห็น** 5 วิ หลัง demo: ทุบ, กันน้ำ, ดึง, ชั่งน้ำหนัก — ทดสอบจริงตามที่สินค้าอ้าง
- ขยาย before/after เป็น 6 วิ พร้อมเงื่อนไขการเทียบที่พูดบอกชัด (แสงเดียวกัน, ไม่ใช้ฟิลเตอร์)
- เพิ่มบีต **ตอบคอมเมนต์ยอดฮิต** 4 วิ: นำคำถามจริงจากคลิปก่อนมาตอบพร้อมสาธิต
- เพิ่มบีต **เทียบ 2–3 รุ่น / ขนาด** 4 วิ พร้อมบอกว่าตัวไหนเหมาะกับใคร
- เพิ่มบีต **ข้อเสียที่เจอจริง** 3 วิ ก่อนช่วงราคา (เพิ่มความน่าเชื่อถือและลดการคืนสินค้า)
- ราคา + โค้ดอยู่ 25–28 วิ, ปักตะกร้า CTA ปิด 28–30 วิ

## หมายเหตุ

**Assets ที่ต้องมีก่อนเริ่ม:**
- [ ] สินค้าตัวจริงอยู่ในมือครีเอเตอร์ (ไม่ใช่แค่ภาพจากร้าน) — เป็นเงื่อนไขบังคับของเทมเพลตนี้
- [ ] ภาพ before/after ที่ถ่ายเอง สภาพแสงและมุมเดียวกัน ไม่แต่งสีฝั่ง after
- [ ] ราคา ณ วันถ่าย + โค้ดส่วนลดที่ยังใช้ได้จริง + วันหมดอายุโค้ด
- [ ] ลิงก์สินค้า / รหัสร้านที่ปักตะกร้าแล้ว และเช็กว่าสต็อกยังมี

**Compliance:**
- ต้องใช้สินค้าจริงและแสดงการใช้งานจริง ห้ามรีวิวจากภาพร้านอย่างเดียว
- ห้ามแต่งส่วนลด / ราคา "ก่อนลด" ที่ไม่เคยขายราคานั้นจริง และห้ามโค้ดหมดอายุ
- ต้องเปิดเผยว่าเป็น affiliate / มีค่าคอมมิชชัน ตามกฎแพลตฟอร์ม (เช่น แท็กสินค้าโปรโมตของ TikTok Shop)
- Before/after ห้ามใช้ฟิลเตอร์หรือปรับแสงเฉพาะฝั่ง after — ถ้าผลลัพธ์ขึ้นกับบุคคลให้ใส่หมายเหตุบนจอ
- ห้ามคัดลอกคลิป / เสียง / สคริปต์ของครีเอเตอร์คนอื่นมาใช้ซ้ำ
- คำเคลมด้านสุขภาพ–ความงาม ปฏิบัติตามกฎโฆษณาของแพลตฟอร์มอย่างเคร่งครัด
