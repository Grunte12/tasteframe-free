## 3. ข้อความหลักหนึ่งเดียว (One-Message Rule)

> กติกาเหล็ก: คลิปนี้พูดได้แค่ประโยคเดียว ถ้าผู้ชมจำได้ประโยคเดียว ต้องเป็นประโยคนี้
> เขียนให้จบใน 1 ประโยค ไม่เกิน 15 คำ ไม่มีคำว่า "และ" เชื่อม 2 ประโยค

**ข้อความหลัก:** <เช่น "ผิวหมองจากแดด แก้ได้ใน 14 วัน โดยไม่ต้องเข้าคลินิก">

เช็กก่อนไปต่อ:
- [ ] อ่านออกเสียงแล้วเข้าใจในครั้งเดียว
- [ ] มีตัวเลข / เวลา / ผลลัพธ์ที่วัดได้ (ถ้าอ้างได้จริง)
- [ ] ไม่ซ้ำกับข้อความรอง — ข้อความอื่นในคลิปต้องสนับสนุนประโยคนี้เท่านั้น

## 4. Hook 2 วิแรก

> 2 วินาทีแรกตัดสินว่าผู้ชมจะหยุดเลื่อนหรือปัดทิ้ง ต้องระบุให้ชัดทั้งภาพและตัวอักษร ห้ามใช้โลโก้เปิดคลิป

| องค์ประกอบ | รายละเอียด |
|---|---|
| ภาพวินาทีที่ 0.0–2.0 | <เช่น คลิป macro หยดเซรั่มบนผิว / หน้าคนทำหน้าตกใจ / ตัวเลขราคาใหญ่เต็มจอ> |
| ข้อความบนจอ (ไม่เกิน 5 คำ) | <เช่น "หยุด! อย่าเพิ่งซื้อครีมตัวเดิม"> |
| เสียงเปิด (ถ้ามี) | <เสียง pop / เสียงพูดประโยคแรก / เงียบแล้วตัดเข้าเพลง> |
| Pattern ที่ใช้ | <คำถามช็อก / ตัวเลขใหญ่ / before-after / หยุดเลื่อน / เปิดด้วยผลลัพธ์> |

## 7. โทนและสไตล์

- คำบรรยายโทน (เลือก 3 คำ): <เช่น สนุก / เร็ว / น่าเชื่อถือ — ตัวอย่างอื่น: หรู, มินิมอล, อบอุ่น, ตื่นเต้น, เป็นกันเอง, เท่>
- จังหวะการตัด: <เร็วทุก 1–2 วิ / นุ่มนวล glide / ผสม>
- คลิปอ้างอิง (reference): <ลิงก์คลิป 1–3 คลิป + เขียนว่า "ชอบตรงไหน" ของแต่ละคลิป>
- สไตล์ตัวอักษร: <ตัวหนาใหญ่ kinetic type / ตัวเล็กสุภาพ / ผสม>
- สไตล์ภาพ: <ถ่ายจริง / motion graphics ล้วน / ผสมภาพถ่าย + กราฟิก>

## 10. สิ่งที่ห้าม (Forbidden)

- [ ] ห้ามแต่งราคา / ส่วนลด / จำนวนคงเหลือที่ไม่มีจริง
- [ ] ห้ามใช้โลโก้คู่แข่ง หรือภาพสินค้าของร้านอื่น
- [ ] ห้ามอ้างสรรพคุณเกินจริง / อ้างรักษาโรค (กลุ่มอาหารเสริม–สกินแคร์–สุขภาพ)
- [ ] ห้ามใช้ภาพ before/after ที่ไม่ใช่ของลูกค้าจริงโดยไม่ได้รับอนุญาต
- [ ] ห้ามใช้เพลงติดลิขสิทธิ์นอกคลังของแพลตฟอร์ม
- [ ] ห้ามใส่เบอร์โทร / ข้อมูลส่วนบุคคลโดยไม่ได้รับอนุญาต
- [ ] ข้อห้ามเฉพาะแบรนด์นี้: <เช่น ห้ามใช้คำว่า "ถูกที่สุด", ห้ามสี ...>

## 12. โหมดสร้างเลย (Just-Build-It Mode)

> โหมดสร้างเลย = ผู้ใช้สั่งอย่างชัดแจ้งรายโปรเจกต์ให้ข้ามหรือย่อการสัมภาษณ์ครั้งเดียวจบ และยอมรับความเสี่ยงว่างานจะมีส่วนผสมของค่าเริ่มต้นของโมเดลมากขึ้น ตามนิยามใน `references/governance.md` ข้อ 8 — ต้องบันทึกในช่องนี้เท่านั้น ความเงียบหรือความเคยชินจากงานก่อนไม่ถือเป็นการเปิดโหมด และโหมดนี้ **ไม่เคย** ผ่อนกฎความซื่อสัตย์ (ห้ามแต่งหลักฐาน/ราคา) และสิทธิ์ของแอสเซท ไม่ว่ากรณีใด

| รายการ | ค่า |
|---|---|
| มอบอำนาจโหมดสร้างเลย (granted) | <ไม่ / ใช่> |
| ผู้มอบอำนาจ (granted-by) | <ชื่อผู้ใช้ที่สั่งเปิดโหมดนี้> |
| วันที่มอบอำนาจ (date) | <YYYY-MM-DD> |
| ขอบเขต (scope) | <ขอบเขตของการข้าม/ย่อการสัมภาษณ์ เช่น ข้ามทั้งสัมภาษณ์โดยใช้โปรไฟล์เดิมล้วน หรือย่อเหลือเฉพาะช่วงโปรเจกต์ ส่วนใดไม่ผ่อนให้ระบุด้วย เช่น การจ่ายเงินสร้างงานเกินวงเงินยังต้องถามก่อนทุกครั้ง> |
