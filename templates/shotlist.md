## คำศัพท์มุมกล้องและการเคลื่อนกล้อง (Camera Vocabulary)

| คำศัพท์ | ความหมาย (1 บรรทัด) |
|---|---|
| push-in | กล้องค่อย ๆ เคลื่อนเข้าหาตัวแบบ สร้างความรู้สึก "กำลังเข้าใกล้ความจริง" ใช้เปิดเผยสินค้า |
| dolly-out / pull-back | กล้องถอยออก เผยให้เห็นฉากกว้างขึ้น ใช้ปิดช็อตหรือโชว์บรรยากาศรวม |
| pan | กล้องอยู่กับที่แต่หันซ้าย–ขวา ใช้กวาดดูชั้นวางสินค้า / โต๊ะอาหาร / ห้อง |
| tilt | กล้องอยู่กับที่แต่เงย–ก้ม ใช้ไล่จากพื้นขึ้นไปยอดตึก หรือจากจานขึ้นหน้าเจ้าของร้าน |
| orbit | กล้องโคจรรอบตัวแบบ 180°/360° ใช้โชว์สินค้า 3 มิติให้ดูพรีเมียม |
| tracking / follow | กล้องเคลื่อนตามตัวแบบที่กำลังเดิน ใช้ทัวร์ห้อง / เดินเข้าร้าน |
| glide / gimbal move | เคลื่อนกล้องนุ่ม ๆ ต่อเนื่องไม่มีสะดุด ให้ฟีลหรู ใช้กับอสังหาฯ และโรงแรม |
| macro | เลนส์ระยะใกล้มาก เห็นรายละเอียดผิว / หยดน้ำ / เนื้ออาหาร ใช้ทำ hook และช็อตความน่ากิน–น่าใช้ |
| top-down (flat lay) | มุมมองจากด้านบนตรง ๆ 90° ใช้จัดวางสินค้า / ส่วนผสม / unbox บนโต๊ะ |
| low angle | กล้องต่ำยิงขึ้น ทำให้ตัวแบบ / อาคารดูใหญ่และมีพลัง |
| punch-in cut | ไม่เคลื่อนกล้อง แต่ตัดกระโดดเข้าใกล้ทันที (jump cut แบบซูม) เน้นจังหวะตลก / เน้นคำสำคัญ |
| whip pan | ปัดกล้องเร็ว ๆ จนภาพเบลอเพื่อเปลี่ยนฉาก ให้พลังงานสูง นิยมในคลิปรีวิวเร็ว ๆ |
| static / lock-off | กล้องนิ่งสนิท ให้ตัวอักษรหรือตัวแบบเป็นฝ่ายเคลื่อน ใช้กับ kinetic type และราคา slam |
