## เฟส 6 — เรนเดอร์และเสียง (Render & Sound Pipeline)

เฟสนี้คือท่อผลิตเสียงเต็มรูปแบบที่ทำให้สกิลนี้จบงานได้โดยไม่ต้องมีนักตัดต่อเสียงแยกอีกคน ทำงานตามลำดับ **source → place → mix → audio QA → master → mux** ทุกขั้นขับด้วยไฟล์ `audio/sound-design.json` จากเฟส 2.4 และใช้ `references/sound-design.md` เป็นคู่มือประจำเฟส ห้ามมิกซ์จากโน้ตกระจัดกระจายหรือจากความจำ — การแก้เสียงทุกครั้งคือการแก้ JSON แล้วมิกซ์ใหม่เท่านั้น

> **Governance — เฟส 6:** เฟสนี้คือปลายทางของการผลิตแบบ autonomous ตามแพ็กเกจที่ยืนยันในการสัมภาษณ์ — มิกซ์และเรนเดอร์ตามแผนเสียงและสตอรี่บอร์ดที่ล็อกไว้ได้เลย ไม่ต้องยืนยันซ้ำก่อนเรนเดอร์ การส่งมอบคือการรายงานผลพร้อมสรุปสมมติฐานที่ยัง open และข้อยกเว้นที่เกิดระหว่างทาง ข้อยกเว้นเดียวที่หยุดงานได้คือเรื่องสิทธิ์/ความซื่อสัตย์ หรือต้นทุนที่เกินวงเงินซึ่งสัมภาษณ์อนุมัติไว้ (`references/governance.md` ข้อ 8–9)

### 6.1 เตรียมแหล่งเสียง (Source)

- **เสียงพากย์** (ทำตาม `references/thai-layer.md` ทุกข้อ): สร้างเสียงทีละบรรทัดตามบีท (Gemini TTS พร้อม Director's Notes คือค่าเริ่มต้น) แล้ว **วัดความยาวจริงของแต่ละไฟล์** — บรรทัดที่ยาวเกินช่องบีทของมัน: สั่งสร้างใหม่ด้วย pacing ที่เร็วกว่า หรือเร่งด้วย `atempo` ไม่เกิน 1.25 เท่า ห้ามยืดภาพให้ตามเสียงโดยไม่แก้แผน จุดเริ่มของแต่ละบรรทัด = จุดเริ่มบีทของมันพอดี (เลื่อนได้ไม่เกิน ±0.2 วิเมื่อต้องหนีการทับซ้อน) และ path ของไฟล์จริงต้องตรงกับช่อง `vo.lines[].file` ใน sound-design.json
- **เพลงและ SFX**: ใช้เฉพาะไฟล์ที่ผ่านเกทเฟส 3 แล้ว (มีตัวจริงบนดิสก์ + บันทึกที่มาและสัญญาอนุญาตครบ) เสียงที่ในแผนยังเป็นสูตรสังเคราะห์ ffmpeg หรือ earshot bank ID ให้ **เรนเดอร์ออกมาเป็นไฟล์ WAV จริงใน `audio/sfx/` ในขั้นนี้** (สูตร ffmpeg อยู่ใน `references/sound-design.md` §2.2; earshot ใช้ `earshot sfx render <bankId> -o audio/sfx/<ชื่อ>.wav` ตาม §2.3) แล้วเขียน path ลงช่อง `source.file` ของ event นั้น — ขั้นมิกซ์อ่านไฟล์อย่างเดียว ไม่เรียกสูตรหรือ bank เอง และบันทึกวิธีสร้างเสียงสังเคราะห์ทุกตัวลงเครดิตโปรเจกต์ตามจริง

### 6.2 มิกซ์แบบ deterministic (Place & Mix)

- ใช้ `scripts/mix-full.sh <คลิปเงียบ.mp4> <ไฟล์ออก.mp4> <audio/sound-design.json>` — สคริปต์วาง VO, เพลง และ SFX ทุกตัวตาม timecode, trim, gain, pan และ fade ที่ระบุใน JSON, กดเพลงลงใต้ VO ด้วย sidechain compressor ตามค่า ducking ในแผน, รวมทุกชั้นเป็นมิกซ์เดียว แล้วมาสเตอร์และมักซ์ให้ในชุดคำสั่งเดียว ผลลัพธ์ต้องทำซ้ำได้เป๊ะ: JSON เดิม + ไฟล์เดิม = มิกซ์เดิมทุกครั้ง
- งานง่ายที่มีแค่เสียงพากย์ (ไม่มีเพลง ไม่มี SFX) ใช้ `scripts/mix-vo.sh` แบบเดิมได้
- ระดับอ้างอิงระหว่างมิกซ์: VO คือพระเอกและต้องชัดเหนือเพลงเสมอ, เพลงเป็น bed ที่จุด drop ต้องลงตรงจุดที่แผนกำหนด, SFX ทุกตัวต้องได้ยินวัดได้เหนือ bed ในย่านความถี่ของมัน — เสียงที่เพิ่มเข้าไปแล้ววัดผลอะไรไม่ได้ให้ตัดออกจากแผน อย่าเก็บไว้เป็นของประดับ

### 6.3 ตรวจคุณภาพเสียง (Audio QA) — เกทเสียงของเฟสนี้ ต้องผ่านก่อนส่งมอบ

ตรวจบนไฟล์ที่มิกซ์แล้ว (ไฟล์เดียวกับที่จะส่งมอบ) ครบทั้ง 3 กลุ่มและบันทึกผลไว้รายงานผู้ใช้:

1. **ความดังและเพดานเสียง**: integrated loudness อยู่ในช่วง −14 ±1 LUFS และ true peak ไม่เกิน −1 dBTP (วัดด้วย ffmpeg `loudnorm` ในโหมดวัด หรือ `ebur128`; `mix-full.sh` รายงานค่าที่วัดได้จากไฟล์ผลลัพธ์ให้ทุกครั้งที่รัน)
2. **ซิงก์กับภาพ**: SFX สำคัญทุกตัว (hit ตอน price slam, pop ตอนพาดหัวลงจอด, sting ตอน lockup) ต้องลงตรงเหตุการณ์ภาพภายใน ±1 เฟรม — เทียบรายการ event ใน JSON กับเฟรมที่ดึงไว้ในเกท 1 ของเฟส 5
3. **ความสะอาดของเสียง**: ไม่มีช่วงเงียบตายเกินที่แผนตั้งใจ (ยกเว้นช่องเงียบสั้นๆ ก่อน sting ปิดท้ายตามแผน), ไม่มีเสียงคลิกที่หัวหรือท้ายไฟล์, ไม่มีเสียงแตก/คลิป และไม่มีแชนเนลเอียงผิดปกติ (เช็กด้วย `silencedetect` และ `astats`)

ถ้าเครื่องมี **earshot** ติดตั้งอยู่ ให้ใช้มันเป็น "หูเสริม" ในขั้นนี้: `earshot timeline` บนไฟล์สุดท้ายเพื่อยืนยันว่า event ที่วางไว้ถูกตรวจพบจริงและวัด offset จากภาพ, `earshot describe` / `earshot critique` เพื่อเทียบภาพรวมของมิกซ์กับช่วงค่าปกติของงาน launch ระดับโปร แต่ต้องรู้ขีดจำกัดของมัน (สรุปไว้ใน `references/sound-design.md` §5.4): มัน **ตัดสินรสนิยมและอารมณ์แทนคนไม่ได้**, โมเดลไม่ได้ยินเสียงเหนือ ~14 kHz, ป้ายชื่อ event ในมิกซ์ที่แน่นเป็นเพียงคำใบ้ (ถูกประมาณครึ่งเดียวสำหรับเสียงที่โผล่ชัด), และมันไม่ตัดสินเรื่องลิขสิทธิ์ — คำตัดสินสุดท้ายด้านรสนิยมเป็นของ TASTE.md และผู้ใช้เสมอ

เกทเสียงข้อใดตก: แก้ที่ JSON หรือไฟล์ต้นทาง แล้วมิกซ์ใหม่และตรวจซ้ำ ห้ามส่งมอบไฟล์ที่เกทเสียงตกโดยเงียบๆ เช่นเดียวกับเกทภาพในเฟส 5

### 6.4 มาสเตอร์และส่งมอบ (Master & Mux)

มาสเตอร์ริ่งเป็นขั้นสุดท้ายที่อยู่ใน `mix-full.sh` แล้ว (loudnorm แบบวัดก่อนแล้วค่อยปรับสองรอบ: เป้า integrated −14 LUFS, true peak −1 dBTP, LRA ~5–9 ตามช่อง `master` ใน JSON — ถ้าต้องการเป้าอื่นให้แก้ที่ JSON ไม่ใช่แก้ทับที่ไฟล์) ไฟล์ที่ออกจาก 6.2 คือไฟล์ส่งมอบ จากนั้น:

1. รันเกท 4 (`scripts/verify.sh`) บนไฟล์สุดท้าย **พร้อมเสียง** ตัวนี้อีกครั้ง — ไม่ใช่บนไฟล์เงียบ
2. ดึงเฟรมจากไฟล์สุดท้ายตรวจซ้ำอย่างน้อยเฟรมเปิด, เฟรมบีท 2, เฟรม lockup ปิดท้าย
3. เช็กลิสต์ส่งมอบ:
   - [ ] ไฟล์เปิดเล่นได้จริง (ffprobe อ่านครบ, มี moov atom — ไฟล์ที่เรนเดอร์ขาดกลางทางจะเปิดไม่ได้)
   - [ ] ความยาว/ขนาด/codec ตรงแผน
   - [ ] ข้อความไทยถูกต้องทุกบีท โลโก้เป็นไฟล์จริง
   - [ ] เสียงพากย์ครบทุกบรรทัด ตรงบีท ไม่ทับกัน และผล audio QA (ข้อ 6.3) ผ่านทั้ง 3 กลุ่ม
   - [ ] ค่ามาสเตอร์ที่วัดได้จริงอยู่ในเป้า (−14 ±1 LUFS, true peak ≤ −1 dBTP)
   - [ ] `audio/CREDITS.md` ของโปรเจกต์บันทึกที่มา+สัญญาอนุญาตของไฟล์เสียงทุกไฟล์ที่ใช้จริงครบ (รวมถึงเสียงสังเคราะห์ที่ระบุวิธีสร้าง)
   - [ ] ชื่อไฟล์สื่อความหมาย (สินค้า_ความยาว_แพลตฟอร์ม.mp4)
4. รายงานผู้ใช้: ลิงก์ไฟล์ + สเปก + ผลเกททั้ง 5 + ผล audio QA และค่ามาสเตอร์ที่วัดได้ + แอสเซทที่ใช้ — ห้ามอ้างว่าตรวจแล้วถ้าไม่ได้ตรวจ
## โหมดล้มเหลวที่เจอจริง (Failure Modes — เช็คก่อนโทษเอนจิน)

- **ไฟล์เรนเดอร์เปิดไม่ได้ / ไม่มี moov atom** — เรนเดอร์ถูกฆ่ากลางทาง (เครื่อง restart, session หลุด) หรือมีการเปลี่ยนชื่อไฟล์ระหว่าง mux ให้เรนเดอร์ใหม่ตรงไปยัง path ปลายทาง และ `ffprobe` ทุกครั้งก่อนส่ง
- **ฟอนต์ไทยเป็น tofu หรือฟอนต์ผิดตัว** — ฟอนต์โหลดจาก CDN ไม่สำเร็จใน sandbox: bundle ไฟล์ฟอนต์ในโปรเจกต์และประกาศ `@font-face` จากไฟล์ local
- **เฟรมแรกๆ ภาพหาย/โลโก้มาช้า** — ตัวจับเฟรมเริ่มก่อนภาพ decode เสร็จ: รอ image load + font load ให้ครบก่อนเฟรมแรก (Track C สำคัญมาก)
- **TTS อ่านคำสั่งสไตล์ออกเสียงไปด้วย** — ใส่คำสั่งแบบประโยคอิสระนำหน้าข้อความ: ใช้ฟอร์แมต Director's Notes / Transcript เท่านั้น (ดู thai-layer)
- **อิโมจิเป็นไอคอน** — อิโมจิเรนเดอร์เป็น glyph สีของแพลตฟอร์ม ไม่สนพาเลตต์แบรนด์ และอาจกลืนกับพื้นหลัง: วาดไอคอนด้วย SVG/CSS ในสีธีมแทน
- **ตัวเลขในเคาน์เตอร์ยังวิ่งตอนตัดฉาก** — ตั้งเวลาฉากจากจุดที่เคาน์เตอร์ "ต้องนิ่ง" ถอยหลังไป ไม่ใช่จากจุดเริ่ม
- **ช่องว่างใน flex รอบตัวอักษรใหญ่ผิดสเกล** — `gap`/`margin` หน่วย em อ้างอิงฟอนต์ของ parent ไม่ใช่ของตัวข้อความ: ใช้ px ในคอนเทนเนอร์รอบตัวอักษรใหญ่
- **เรนเดอร์ช้าผิดปกติ** — มักมาจากเลเยอร์ blur/mesh ขนาดใหญ่ที่ต้องคำนวณซอฟต์แวร์ทุกเฟรม: ลดขนาดเลเยอร์เบลอหรือ pre-render เป็นภาพนิ่ง
