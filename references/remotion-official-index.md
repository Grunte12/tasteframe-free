# สารบัญชุดสกิลทางการของ Remotion (Remotion Official Skills Index)

ไฟล์นี้คือ "แผนที่" ของชุด Agent Skills ทางการที่ทีม Remotion ดูแลเอง — **TASTEFRAME ไม่ได้บรรจุไฟล์ของชุดนั้นมาในตัว** และห้ามคัดลอกไฟล์ ข้อความ หรือโค้ดจากชุดนั้นมาฝังในสกิลนี้ (ชุดทางการไม่มีสัญญาอนุญาตเปิดเผยแพร่ จึงถือว่าสงวนสิทธิ์ทั้งหมดโดยปริยาย) สิ่งที่ไฟล์นี้ให้คือ: ชื่อหัวข้อ (ข้อเท็จจริง), คำอธิบายที่เขียนขึ้นเองว่าแต่ละสกิลใช้ตอนไหน, และวิธีติดตั้งจากต้นทาง

ทำไมต้องใช้ของต้นทางเสมอ: ชุดทางการเป็นเอกสารมีชีวิตที่อัปเดตตามเวอร์ชันของเฟรมเวิร์ก การติดตั้งจากต้นทางทำให้ผู้ใช้ได้ฉบับที่ตรงกับ Remotion เวอร์ชันที่ตัวเองใช้เสมอ — ดีกว่าสำเนาแช่แข็งที่ล้าสมัยและผิดกฎหมาย

## วิธีติดตั้ง (ต้นทางเท่านั้น)

```bash
npx skills add remotion-dev/skills
```

หรือตอนสร้างโปรเจกต์ใหม่ด้วย `bun create video` จะมีตัวเลือกให้เพิ่มชุดสกิลให้อัตโนมัติ เอกสารต้นทาง: remotion.dev/docs/ai/skills

**หน้าที่ของเอเจนต์:** เมื่อเริ่มงานโหมด Remotion (ต้นเฟส 4 Track A หรือเมื่อต้องเขียน/แก้โค้ด Remotion) ให้ตรวจก่อนว่าชุดสกิลทางการพร้อมใช้ในสภาพแวดล้อมหรือไม่ — ถ้าไม่มี ให้บอกผู้ใช้รันคำสั่งติดตั้งด้านบนเพียงคำสั่งเดียว **ห้าม**พยายามสร้างชุดนั้นขึ้นมาแทน ห้ามดาวน์โหลดมาแฝงในโปรเจกต์ และห้ามอ้างว่า TASTEFRAME มีสำเนาของมัน

## แผนที่หัวข้อ — สกิลทางการแต่ละตัว ใช้ตอนไหนในงาน TASTEFRAME

| สกิลทางการ | ครอบคลุมอะไร (สรุปเอง) | เปิดใช้เมื่อ (ผูกกับเฟสของเรา) |
|---|---|---|
| `remotion-best-practices` | ตัวรวม/ตัวชี้ทางที่ครอบสกิลทางการทุกตัว — จุดเริ่มเมื่อยังไม่แน่ใจว่าปัญหาอยู่หมวดไหน | เมื่อติดปัญหา Remotion แล้วระบุหมวดไม่ได้ |
| `remotion-markup` | กฎเชิงลึกของการเขียนมาร์กอัป Remotion: การวาง composition, การจัดลำดับฉาก (sequencing), จังหวะเวลา (timing), ทรานซิชัน, เอฟเฟกต์, เสียงและ SFX, เสียงพากย์, การวัดตัวอักษรและไฮไลต์ข้อความ, งาน 3D, Lottie, GIF, ฟอนต์, การใช้ ffmpeg, การตรวจจับช่วงเงียบ | เฟส 2 (วาง timing/sequencing/ทรานซิชันในแผน) และเฟส 4 (เขียนโค้ดจริง) — แหล่งความถูกต้องของเฟรมเวิร์กหลัก |
| `remotion-captions` | การทำแคปชัน/ซับไตเติล: การนำเข้าไฟล์ SRT, การถอดเสียงเป็นแคปชัน, รูปแบบการแสดงแคปชันบนจอ | เฟส 4 และ 6 ตอนทำแคปชัน — ใช้คู่กับ `references/thai-layer.md` ของเรา ซึ่งกำกับเรื่องตัวอักษรไทยเสมอ |
| `remotion-create` | การสร้างโปรเจกต์หรือ composition ใหม่ รวมถึงการวางเลย์เอาต์วิดีโอและ Tailwind ในโปรเจกต์ Remotion | เริ่มโปรเจกต์ใหม่ในเฟส 4 |
| `remotion-maps` | แอนิเมชันแผนที่: แผนที่นิ่ง เส้นทางและหมุดเคลื่อนไหว คำอธิบายเชิงภูมิศาสตร์ รวมถึง flyover 3D | เฉพาะช็อตแผนที่ (เช่น คลิปอสังหาฯ/ท่องเที่ยว) ในเฟส 2–4 |
| `remotion-multimedia` | การอ่านข้อมูลสื่อด้วย Mediabunny: ความยาววิดีโอ/เสียง ขนาดเฟรม — ข้อมูลดิบสำหรับวางแผนและตรวจไฟล์ | เฟส 3 (ตรวจแอสเซท) และเฟส 5–6 (ตรวจไฟล์ผลลัพธ์) |
| `remotion-render` | การสั่งเรนเดอร์เป็นวิดีโอหรือภาพนิ่ง รวมถึงวิดีโอพื้นหลังโปร่งใส | เฟส 6 ตอนมาสเตอร์/ส่งมอบ |
| `remotion-studio` | การเปิด Studio เพื่อพรีวิวงาน | ระหว่างเฟส 4–5 เมื่อต้องดูพรีวิวแบบโต้ตอบ |
| `remotion-interactivity` | การทำให้องค์ประกอบในโค้ดแก้ไขได้จาก Studio (เลือก/ปรับค่าในไทม์ไลน์ได้) | เฟส 4 เมื่อผู้ใช้ต้องการปรับงานเองใน Studio ต่อ |
| `remotion-saas` | สถาปัตยกรรมการทำ Remotion เป็นผลิตภัณฑ์/บริการ: เฟรมเวิร์กฝั่งแอป ตัวเล่น (Player) และการเรนเดอร์ระดับโปรดักชัน | นอกขอบเขตคลิปทั่วไป — เฉพาะเมื่องานคือการสร้างเครื่องมือ/บริการจาก Remotion |
| `remotion-docs` | ค้นและดึงเอกสาร Remotion ฉบับปัจจุบันมาเป็น Markdown เพื่ออ้างอิง API/props ที่ถูกต้องก่อนลงมือเขียน | ทุกครั้งที่ต้องยืนยัน API หรือ props ก่อนเขียนโค้ดเฟส 4 |
| `remotion-upgrade` | การอัปเกรด Remotion แพ็กเกจที่เกี่ยวข้อง และชุดสกิลทางการที่ติดตั้งไว้ | เมื่อเวอร์ชันไม่ตรงหรือก่อนเริ่มโปรเจกต์ที่ค้างนาน |

## การแบ่งงานระหว่างชุดทางการกับ TASTEFRAME

- **ชุดทางการ = ความถูกต้องของเฟรมเวิร์ก** — Remotion ทำงานอย่างไร, API ใช้อย่างไร, เรนเดอร์อย่างไรให้ไม่พัง
- **TASTEFRAME = รสนิยม ทิศทาง คุณภาพ และเลเยอร์ไทย** — งานควรหน้าตาแบบไหน ตัดจังหวะไหน เสียงเป็นอย่างไร ตัวอักษรไทยต้องระวังอะไร และเกท QA ผ่านหรือไม่ ทั้งหมดกำกับโดย TASTE.md ของผู้ใช้
- เมื่อค่าเริ่มต้นหรือคำแนะนำจากชุดทางการขัดกับ TASTE.md (เช่น สี ฟอนต์ สไตล์การเคลื่อนไหว จังหวะตัด) **โปรไฟล์ของผู้ใช้ชนะ** ตามลำดับความขัดแย้งใน SKILL.md (ข้อเท็จจริง/สิทธิ์ > TASTE.md > บรีฟ > ทิศทางที่เลือก > สูตร/เทมเพลต) — ชุดทางการอยู่ชั้น "วิธีทำเชิงเทคนิค" ไม่ใช่ชั้นรสนิยม
- กฎเหล็กของ TASTEFRAME (motion grammar, เกทแอสเซท, เกท QA) บังคับเหนือแนวปฏิบัติทั่วไปเสมอ

> **ข้อควรระวังเรื่องสัญญาอนุญาตของตัวเฟรมเวิร์ก:** Remotion (ตัวเฟรมเวิร์ก/ไลบรารี) มีสัญญาอนุญาตของตัวเองแยกจากชุดสกิลนี้ — ใช้ฟรีสำหรับบุคคลและทีมเล็ก และต้องใช้สัญญาเชิงพาณิชย์เมื่อทำในระดับบริษัท/องค์กรตามเงื่อนไขของเขา ผู้ซื้อ TASTEFRAME ต้องตรวจสิทธิ์การใช้งาน Remotion ของตัวเองก่อนใช้เชิงพาณิชย์เสมอ TASTEFRAME ไม่ได้รับประกันสิทธิ์ของเฟรมเวิร์กให้
